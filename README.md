# Credit Risk

A notebook workspace centered on [Credit Risk Regression.ipynb](Credit%20Risk%20Regression.ipynb).

## Start here

1. Open the notebook in Jupyter.
2. Review its imports, input paths, target definition, and execution order before running cells.
3. Supply the expected data and install the packages required by the notebook in a separate environment.
4. Run the notebook from the beginning and retain the environment versions with any new results.

## Repository contents

The notebook is the research artifact. Separate datasets, dependency manifests, trained-model files, and a reusable Python package are not committed in this repository.

## Reproducing an experiment

Record the dataset source and version, target, split policy, preprocessing, package versions, random seeds, and evaluation metrics for each run. Saved notebook outputs should be treated as historical experiment records until the workflow is rerun in the recorded environment.
